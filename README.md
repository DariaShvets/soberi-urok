# Собери урок

Русскоязычный банк педагогических приёмов и конструктор урока для учителей разных предметов. Версия для GitHub Pages: сайт работает в браузере, без отдельного сервера.

## Что входит

- 149 карточек: педагогические приёмы, организация работы и короткие филлеры.
- 12 волшебных карт с игровыми механиками.
- Поиск по названию и описанию; фильтры по этапу, времени, классу, форме работы и источникам.
- Сборка маршрута урока, настройка заданий, времени и признаков достижения результата.
- Личные карточки, избранное, сохранённые уроки.
- Скачивание редактируемого плана в Word (.doc) для просмотра, правки и печати; обмен редактируемым уроком через JSON.
- Резервная копия всех личных материалов и загрузка из файла.

Шесть блоков — схема навигации по учебным задачам. Структуру конкретного урока выбирает учитель. Инструкции адаптированы для конструктора; у карточек указаны внешние источники.

План Word скачивается кнопкой **Скачать план (.doc)** в конструкторе или **План (.doc)** на карточке сохранённого урока. Это двоичный документ Word 97–2003 с текстом в Unicode; сторонняя конвертация и загрузка личных данных на сервер не требуются.

## Личные сохранения и управление

Личные уроки, карточки и избранное сохраняются в текущем браузере на текущем устройстве. На другом устройстве, в другом браузере и после очистки данных сайта они автоматически не появятся. В режиме инкогнито данные могут исчезнуть при закрытии окна.

Для переноса откройте **Мои уроки → Резервная копия**, затем на другом устройстве — **Загрузить из файла**. Для передачи одного урока нажмите **Для переноса (.json)** на его карточке. Импорт объединяет материалы; при конфликте изменённый урок получает отдельную копию.

При переходе с адреса GitHub на собственный домен браузер использует отдельные сохранения. Перед переходом скачайте резервную копию и загрузите её уже на окончательном адресе.

Общим банком управляет владелец репозитория через свой аккаунт GitHub. Отдельного пароля администратора сайта в этой версии нет. Кнопка **Свой приём** сохраняет личную карточку только у её автора. Общих учительских аккаунтов, серверной базы и автоматической синхронизации личных уроков эта версия не предусматривает.

## Публикация через GitHub Actions

1. В аккаунте `DariaShvets` создайте публичный репозиторий `soberi-urok`. Основная ветка — `main`.
2. Загрузите содержимое этой папки в корень репозитория. Не загружайте папку `node_modules` и локальные сохранения учителей. Файл `.github/workflows/pages.yml` должен попасть в репозиторий вместе с исходниками.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Во вкладке **Actions** запустите **Publish lesson constructor → Run workflow**, если публикация не началась автоматически после загрузки.
5. Дождитесь успешного завершения задания `deploy`. Адрес публикации будет указан в **Settings → Pages** и в результате запуска workflow.

Workflow проверяет типы, данные каталога и сохранение материалов, собирает сайт и публикует папку `docs`. Для изменений исходников и `data/` достаточно сделать commit в `main`.

Если GitHub не разрешает загрузить workflow через подключённое приложение, владелец может добавить этот файл через интерфейс GitHub. Другой вариант публикации уже собранного сайта: **Source → Deploy from a branch**, ветка **main**, папка **/docs**, затем **Save**. В таком варианте после изменения исходников нужно локально выполнить сборку и загрузить обновлённую папку `docs`.

## Домен soberi-urok.ru

Сначала завершите публикацию на GitHub Pages, затем добавьте домен на стороне GitHub, и только после этого меняйте DNS у регистратора.

1. В **Settings → Pages → Custom domain** укажите `soberi-urok.ru` и сохраните. При наличии возможности подтвердите владение доменом в настройках аккаунта GitHub по предложенной TXT-записи.
2. В REG.RU откройте домен → управление DNS-записями. Если используются DNS-серверы другого провайдера, записи меняются у этого провайдера.
3. Для корня домена (`@` или пустое имя, в зависимости от интерфейса) задайте четыре A-записи:

| Имя | Тип | Значение |
| --- | --- | --- |
| @ | A | 185.199.108.153 |
| @ | A | 185.199.109.153 |
| @ | A | 185.199.110.153 |
| @ | A | 185.199.111.153 |
| www | CNAME | dariashvets.github.io |

Для `@` и `www` проверьте старые записи парковки/переадресации: они не должны конфликтовать с новыми. Почтовые MX и TXT-записи домена сохраняйте. Запись CNAME для `www` указывается без `https://` и без имени репозитория.

4. Дождитесь успешной DNS-проверки в **Settings → Pages**. Обновление DNS может занять до 24 часов.
5. Когда GitHub выпустит сертификат и опция станет доступна, включите **Enforce HTTPS**. Затем проверьте `https://soberi-urok.ru` и вариант с `www`.

В сборке предусмотрен файл `docs/CNAME` с именем домена. Сам по себе этот файл не заменяет настройку **Custom domain** и DNS-записей.

Официальные инструкции: [настройка собственного домена](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site), [публикация через GitHub Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Как пополнять общий банк

- `data/curated.json` — общие карточки приёмов. При добавлении сохраняйте формат соседней карточки, используйте уникальный `id` и рабочую ссылку на источник.
- `data/magic.json` — игровые механики.
- После изменения сделайте commit в `main`. При публикации через Actions сайт пересоберётся автоматически, если проверки успешны.
- В режиме публикации `main /docs` обновляйте исходные данные, выполняйте сборку и загружайте полученную папку `docs`. Ручная правка только `docs/data/curated.json` будет перезаписана следующей сборкой.

Общий репозиторий публичный. В нём должны находиться код и общедоступные методические материалы. Личные резервные копии преподавателей хранятся отдельно у преподавателей.

## Локальная разработка

Нужен Node.js 24 и npm.

```sh
npm install
npm run dev
```

Проверка и сборка:

```sh
npm run check
npm test
npm run build
```

Готовый сайт находится в `docs/`. Для проверки откройте его через HTTP-сервер или GitHub Pages: двойной щелчок по `docs/index.html` не заменяет размещение сайта.

Генератор `.doc`: [Alpaq92/JSDoc](https://github.com/Alpaq92/JSDoc), лицензия 0BSD. Закреплённая версия и описание адаптации указаны в `vendor/jsdoc/UPSTREAM.md`.
